## 저는 이러한 강점을 가지고 있습니다
1. 하나의 문제에 직면하면 끝까지 해결하고자 하는 집요함!
 * 매 프로젝트에서 완성도가 낮거나 구현도가 낮으면 해당 프로젝트의 작업에만 집중해서 어떻게든 완성시키고자 하였습니다.
2. 개발자적 사고를 갖고 새로운 내용을 빠르게 이해합니다.
 * 웹 프론트엔드와 Python에 대한 정보는 지식이 전무한 상태였으나 기존 개발자들의 코드 스타일과 함수 이름 특성을 빠르게 캐치해서 5일만에 웹 프론트엔드 정보를 습득하였습니다.
 * 이외에도 프로그래밍에만 집중하는 것이 아닌 해당 프로젝트의 도메인 지식을 얻고 이해하고서 의뢰에 맞게 개발하도록 합니다.
3. 최대한 다른 사람들의 의견을 수용합니다.
 * 프로젝트 결과가 안좋을 수 있는 의견은 이에 대한 반박과 이유, 그리고 설득을 합니다.
 * 저와 다른 의견이 나오더라도 그 의견을 존중합니다.
*****
## 저는 이러한 기술을 잘 다룹니다.
1. Linux
   * 대다수의 서버 관련 프로젝트는 Azure Compute Machine을 사용해서 실제 웹, 서버로 운영을 해본 경험이 있습니다.
   * 개인 서버인 라즈베리 파이를 통해 Spring, DB를 배포하여 사용하고 WSL을 통해 Pytorch, Tensorflow, scikit 프로젝트를 진행했었습니다.
2. DB
   * 학과에서 주력으로 배웠던 과목입니다. 데이터베이스 설계와 구축, 운용까지 해보면서 데이터베이스 다루는 것에 흥미를 느꼈었습니다. 마침 게임 서버에서도 유저 DB와 아이템/콘텐츠 DB가 존재하기에 적용이 가능하다고 보고 있습니다.
3. 게임 엔진
   * 고등학교 때 게임메이커 스튜디오로 팀원들과 같이 닷지 게임을 구현했었으며 저는 팀장임과 동시에 프로그래밍을 담당했습니다. 이때 만든 게임이 인기가 있었으며 동아리 축제에서 우수상을 받았습니다.
   * 대학교에서도 학과 동아리를 통해 Unity를 접할 수 있었으며 캡스톤 디자인 프로젝트인 얼굴 추적 및 신체 추적 프로젝트에서 신체 추적 프로그래밍을 담당하였습니다.
   * 이외에도 수업을 들을 때 게임에는 어떻게 적용할까를 생각하면서 게임 메커니즘에 대한 이해를 높였습니다.
4. 웹 프로그래밍
   * KT에서 진행하는 에이블스쿨 8기에서 프론트엔드 내용인 HTML5, CSS, Javascript를 배웠으며 이를 활용하여 이전에 구현하지 못했던 프론트엔드 사이트를 만들 수 있게 되었습니다.
   * 별개로 DB를 활용한 Spring Boot 기반 프로젝트가 있습니다.
